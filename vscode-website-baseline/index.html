Finding 1, highest priority

"Free" creates a product and pricing contradiction.

"Is it, like, an extension? Or the actual installation?"

P14, daily VS Code user

"It's like we're using open source one because it's free... And then it's like, here's AI agents. Try it for you, and then you can start paying us."

P12, daily VS Code user
Act now
  1. Split the CTA into "New to VS Code: Download" and "Already use VS Code: Open agents."
  2. State what is free, what is metered or paid, and why GitHub sign-in is needed.
  3. Name the object clearly: agents are available in VS Code, not a separate product.

Prioritized action plan

Fix trust first.
Build proof next.

Now

Clarify conversion

  • Two labeled install paths
  • Plain free and paid boundary
  • One-line product definition
  • Homepage link to Agents
Next

Add trust signals

  • Real prompt-to-result demo
  • Adoption and ecosystem proof
  • Editor credibility before autonomy
  • Visually anchor key content
Later

Support switching

  • Safe "try a prompt" sandbox
  • Transparent benchmarks
  • Role-based entry points
  • Theme preference exploration

The decision

Do not change the bet.
Change the handoff.

Keep agents in the hero. Make VS Code understandable to a newcomer, separate download from in-product activation, explain the commercial boundary, and give switchers evidence they can trust.

Evidence boundary
  • Four valid sessions, directional only
  • No AI-naive participants
  • Half the sample were incumbents
  • Agents-page navigation was moderator-directed
  • No telemetry was pulled or estimated
